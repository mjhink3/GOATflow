Swap the AI engine from OpenAI GPT 
to Google Gemini. Here are the 
specific changes needed:

1. DEPENDENCY CHANGE:
Remove: openai
Add: google-generativeai

Update pyproject.toml dependencies 
to replace openai with:
google-generativeai>=0.8.0

2. IMPORT CHANGE:
Remove all OpenAI imports:
from openai import OpenAI
client = OpenAI()

Replace with:
import google.generativeai as genai
genai.configure(api_key=os.environ.get("GEMINI_API_KEY"))

3. API CALL CHANGE:
Find every place in the code that 
calls the OpenAI API for the 
Churn Engine. It will look something 
like this:

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[...]
)

Replace each one with:

model = genai.GenerativeModel("gemini-1.5-flash")
response = model.generate_content(prompt)
result = response.text

Note: Gemini uses a single prompt 
string rather than a messages array.
Combine your system prompt and 
user content into one string:

prompt = f"""
{system_prompt}

User input:
{user_content}
"""

4. ENVIRONMENT VARIABLE CHANGE:
Replace all references to:
os.environ.get("OPENAI_API_KEY")
with:
os.environ.get("GEMINI_API_KEY")

5. MODEL TO USE:
Use "gemini-1.5-flash" — 
it is fast, capable, and on 
the free tier.

If gemini-1.5-flash is not available
fall back to "gemini-pro".

6. ERROR HANDLING:
Keep all existing error handling 
but update any OpenAI-specific 
exception types to general 
Exception catches since Gemini 
uses different error classes.

7. VERIFY:
After making all changes confirm:
- pyproject.toml no longer references openai
- No OpenAI imports remain anywhere
- All API calls use the Gemini SDK
- GEMINI_API_KEY is the only 
  AI-related environment variable
- The Churn Engine still produces 
  the same structured output format
  (prioritized Tracks with the 
  same fields as before)

Do not change anything else — 
same UI, same database, same 
reward system, same everything.
Only the AI engine changes.
