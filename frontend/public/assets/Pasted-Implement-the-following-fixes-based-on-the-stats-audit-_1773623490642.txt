FIX 1 — SPEED BONUS TIERS
Pass time estimate to server on completion
═══════════════════════════════════════

Currently when a user marks a Track 
complete the frontend does not send 
the time estimate to the server.

Fix the Track completion flow:

When the Complete button is tapped 
on a Track card, before sending the 
completion request to the server, 
check localStorage for a time estimate 
stored against this Track ID:

const estimate = localStorage.getItem(
  'goatflow_estimate_' + trackId
);

Include this estimate value in the 
completion API request payload:

{
  trackId: trackId,
  completedAt: Date.now(),
  timeEstimateMinutes: estimate || null
}

On the server side, receive this value 
in the completion endpoint and use it 
to calculate the speed bonus tier:

IF timeEstimateMinutes is provided:
  Calculate actual elapsed time 
  from track creation to completion.
  
  IF elapsed <= timeEstimateMinutes:
    Award +25 Hay speed bonus
    Log bonus type: 'precision'
    
  ELSE IF elapsed <= timeEstimateMinutes * 2:
    Award +10 Hay speed bonus
    Log bonus type: 'close'
    
  ELSE IF same calendar day:
    Award +5 Hay speed bonus
    Log bonus type: 'sameday'

IF timeEstimateMinutes is null:
  Use existing behavior:
  +10 Hay for same-day completion
  Log bonus type: 'sameday_default'

Show the appropriate bonus message 
on completion animation:
+25: "⚡ On time — +25 Hay"
+10: "⚡ Close — +10 Hay"  
+5: "⚡ Same day — +5 Hay"
Default +10: "⚡ Speed bonus — +10 Hay"

FIX 2 — PRECISION RATE
Client-side calculation for beta
═══════════════════════════════════════

Precision Rate cannot be calculated 
server-side without a schema change.
For beta, implement it fully client-side:

When a Track is marked complete 
and a time estimate exists in localStorage:

1. Calculate actual elapsed time:
   const logged = track.createdAt
   const completed = Date.now()
   const actualMinutes = 
     (completed - logged) / 60000

2. Retrieve the stored estimate:
   const estimated = localStorage.getItem(
     'goatflow_estimate_' + trackId
   )

3. Determine if precise:
   const isPrecise = 
     actualMinutes <= parseInt(estimated)

4. Update running totals in localStorage:
   const stats = JSON.parse(
     localStorage.getItem(
       'goatflow_precision_stats'
     ) || '{"precise":0,"total":0}'
   )
   stats.total += 1
   if (isPrecise) stats.precise += 1
   localStorage.setItem(
     'goatflow_precision_stats',
     JSON.stringify(stats)
   )

5. Calculate and display Precision Rate:
   const rate = stats.total >= 5 
     ? Math.round(
         (stats.precise / stats.total) * 100
       )
     : null

Display in stat card:
- If rate is null (under 5 estimates): 
  show "—" with sub-label 
  "Complete 5 timed Tracks to unlock"
- If rate exists: show percentage
  with color coding:
  Above 75%: #4ade80
  50-74%: #f59e0b
  Below 50%: #ef4444

FIX 3 — HORN EFFECTIVENESS
Client-side calculation for beta
═══════════════════════════════════════

Horn Effectiveness is stored in 
localStorage as goatflow_priority_feedback.
Build the calculation and display 
from this existing data.

Calculate rolling 30-day effectiveness:

function getHornEffectiveness() {
  const feedback = JSON.parse(
    localStorage.getItem(
      'goatflow_priority_feedback'
    ) || '[]'
  )
  
  const thirtyDaysAgo = 
    Date.now() - (30 * 24 * 60 * 60 * 1000)
  
  const recent = feedback.filter(
    f => f.timestamp >= thirtyDaysAgo
  )
  
  if (recent.length < 10) return null
  
  const correct = recent.filter(
    f => f.ranked === 'correct'
  ).length
  
  return Math.round(
    (correct / recent.length) * 100
  )
}

Display in the Horns side panel 
below the Horn list, above the 
Lock In My Horns button:

Divider line

Label: "Horn Effectiveness"
DM Sans 500, 12px, #6b7280

If null (under 10 feedback entries):
Value: "—"
Sub-label: "Rate 10 Tracks to unlock"
DM Sans 400, 11px, #4b5563

If value exists:
Value in Syne 700, 18px, color coded:
  Above 80%: #4ade80
  60-79%: #f59e0b  
  Below 60%: #ef4444

Descriptor line:
Above 80%: "Your Horns are dialed in."
60-79%: "Getting there. Keep refining."
Below 60%: "Your priorities have shifted. 
  Time to update your Horns."
