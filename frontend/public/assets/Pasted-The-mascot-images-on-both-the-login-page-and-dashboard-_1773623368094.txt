ROOT CAUSE NOTE FOR REPLIT
═══════════════════════════════════════

The clipping on both images is caused 
by a parent container somewhere in 
the component tree that has 
overflow: hidden set.

Search the entire component tree 
above both image elements for any 
element with overflow: hidden 
or overflow: clip applied.

Change ALL instances of overflow: hidden 
on containers that are ancestors of 
these two images to overflow: visible.

The only element that should have 
overflow: hidden in the login and 
dashboard layout is the Pasture Gauge 
bar at the bottom — everything else 
should allow the mascot images to 
display at their full natural size.
