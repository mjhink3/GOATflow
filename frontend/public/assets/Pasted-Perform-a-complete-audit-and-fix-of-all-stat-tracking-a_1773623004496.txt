STAT 6 — CLIP RATE
═══════════════════════════════════════

Definition: Completion efficiency 
percentage over a rolling 7-day window.

Formula:
Clip Rate = (Tracks completed in last 7 days
  ÷ Tracks generated in last 7 days) × 100
Rounded to nearest whole number.
Displayed as percentage.

Verify:
- Only counts Tracks from the 
  last 7 calendar days — not all time
- Rolling window updates daily
- Numerator: completed Tracks in window
- Denominator: ALL Tracks generated 
  in window (completed + active + dismissed)
- Shows "—" with sub-label 
  "Complete 5 Tracks to unlock" 
  if fewer than 5 completions total
- Color coding:
  Above 75%: green (#4ade80) border
  50-74%: amber (#f59e0b) border
  Below 50%: red (#ef4444) border
- Nudge card fires when below 60% 
  for 3 consecutive days of app use

═══════════════════════════════════════
STAT 7 — GAIT
═══════════════════════════════════════

Definition: Consecutive calendar days 
on which the user has completed at 
least one Track.

Verify:
- Increments by 1 when user completes 
  a Track on a new calendar day
- Only counts calendar days — 
  multiple completions on the same 
  day count as 1 day not multiple
- Resets to 0 if user goes a full 
  calendar day with no completion
- Does NOT reset if user logs in 
  but does not complete a Track — 
  only resets on a day with zero completions
- Persists last completion date in 
  localStorage as 'goatflow_last_completion_date'
  in ISO date format YYYY-MM-DD
- On each completion check:
  IF today === last_completion_date: 
    no change to streak
  IF today === last_completion_date + 1 day: 
    streak + 1
  IF today > last_completion_date + 1 day: 
    streak resets to 1
- Milestone Goatifications fire at 
  exactly 3, 7, 14, 30 days — 
  verify each milestone fires once only

STAT 9 — PRECISION RATE
═══════════════════════════════════════

Definition: Percentage of Tracks 
with time estimates completed 
within their estimated time.

Formula:
Precision Rate = 
  (Tracks completed within estimate
  ÷ Total Tracks with estimates entered)
  × 100

Verify:
- Only calculated on Tracks where 
  the user entered a time estimate
- Records timestamp when estimate 
  is set on a Track
- Records timestamp when Track 
  is marked complete
- Compares elapsed time to estimate:
  5 min estimate = 300 seconds
  15 min estimate = 900 seconds
  30 min estimate = 1800 seconds
  1 hr estimate = 3600 seconds
  2+ hrs estimate = 7200 seconds
- If elapsed ≤ estimate: 
  count as precise
- If elapsed > estimate: 
  count as imprecise
- Shows "—" until 5 estimates recorded
- Color coding same as Clip Rate
