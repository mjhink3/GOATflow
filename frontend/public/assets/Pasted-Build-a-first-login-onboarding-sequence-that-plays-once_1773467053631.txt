Build a first-login onboarding sequence that plays 
once for new users and never again. Store completion 
in localStorage as 'goatflow_onboarding_complete'.

The sequence has three acts: 
The Animal Parade, The BAM moment, The Tutorial.

═══════════════════════════════════════════════════
TECHNICAL REQUIREMENTS
═══════════════════════════════════════════════════

The entire sequence is a React component 
or vanilla JS overlay that mounts on top 
of the app on first login.

All animations use CSS transitions only — 
no external animation libraries required.

The sequence must be fully functional on 
mobile (under 768px) — all text sizes 
scale down by 15% on mobile, 
emoji sizes scale to 72px on mobile.

After completion or skip, the overlay 
unmounts completely and the normal 
dashboard renders underneath with 
the side panel opening automatically.

Add a way for developers to re-trigger 
the onboarding for testing: 
in the browser console, running 
goatflow_resetOnboarding() 
clears the localStorage flag and 
reloads the page.
