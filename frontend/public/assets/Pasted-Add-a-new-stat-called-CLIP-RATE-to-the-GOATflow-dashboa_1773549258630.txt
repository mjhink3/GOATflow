Add a new stat called CLIP RATE to the 
GOATflow dashboard and user profile.

DEFINITION:
Clip Rate = (Tracks marked complete / 
Total Tracks generated) × 100
Calculated on a rolling 7-day window.
Displayed as a percentage rounded to 
the nearest whole number.
Example: 8 completed out of 10 generated 
= 80% Clip Rate.

DASHBOARD STAT CARD:
Add Clip Rate as a sixth stat card in 
the stat cards row below the Churn Engine button.

Card display:
Icon: ✂️
Value: percentage in white, 
same size as other stat values
Label: "CLIP RATE" in muted gray uppercase
Card border: subtle green #3DAA6A when 
Clip Rate is above 75%
Card border: subtle amber #f59e0b when 
Clip Rate is 50-74%
Card border: subtle red #ef4444 when 
Clip Rate is below 50%

On tap/click, show a small tooltip:
"Tracks completed vs. Tracks generated 
over the last 7 days. Refine your Horns 
to improve your Clip Rate."

SIDE PANEL STATS:
Add Clip Rate to the My Stats section 
in the side panel beneath Cheese Churn Rate.
Label: "Clip Rate"
Value color: matches the same color coding 
as the dashboard card border:
Above 75% → #4ade80 (green)
50–74% → #f59e0b (amber)
Below 50% → #ef4444 (red)

INTELLIGENT NUDGE SYSTEM:
If a user's Clip Rate drops below 60% 
for 3 consecutive days, show a subtle 
nudge notification inside the app 
(not a push notification — in-app only):

Notification card appears at the top 
of the Track list, styled as a soft 
amber panel:
Background: rgba(245,158,11,0.08)
Border: 1px solid rgba(245,158,11,0.3)
Border-radius: 8px
Padding: 10px 14px

Text in DM Sans 400, 13px, #f59e0b:
"Your Clip Rate is at [X]% this week. 
If Tracks feel off-priority, 
add a Horn to dial it in. 
The AI gets sharper every time you do."

Small "Refine a Horn →" link at the end 
that opens the Horns side panel directly.
Dismiss button (×) top right — 
dismissed state stored in sessionStorage 
so it reappears the next day if 
Clip Rate is still low.

FIRST TIME EXPERIENCE:
For new users with fewer than 5 completed 
Tracks, display "—" instead of a percentage 
with a small label beneath: 
"Complete 5 Tracks to unlock"
This prevents a misleading 0% showing 
for brand new users.
