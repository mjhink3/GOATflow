PART 2 — FLOATING VOICE RECORD BUTTON
═══════════════════════════════════════════════════

Remove the existing Voice Drop button from 
its current position in the input zone.

Replace it with a persistent floating action 
button fixed to the bottom right corner of 
the screen at all times — visible whether 
the user is viewing the input zone, scrolling 
through Tracks, or anywhere else in the app.

BUTTON DESIGN — IDLE STATE:
Position: fixed, bottom: 80px, right: 16px
(80px from bottom so it sits above the 
Pasture Gauge / bottom nav bar)
Size: 58px × 58px circle
Background: #7c3aed (purple)
Border: 2px solid #a78bfa
Border-radius: 50%
Box-shadow: 0 4px 20px rgba(124, 58, 237, 0.5)
Z-index: 40
Icon: microphone SVG, white, 24px centered

Add a small label tag that appears to the 
left of the button on first load for 3 seconds 
then fades away permanently:
Text: "Voice Drop"
Background: rgba(10,10,20,0.9)
Border: 1px solid rgba(124,58,237,0.4)
Color: #a78bfa
Font: DM Sans 400, 11px
Border-radius: 20px
Padding: 4px 10px
Margin-right: 8px from button edge

BUTTON BEHAVIOR — TAP TO RECORD:

State 1 — IDLE:
Purple circle, microphone icon, subtle pulse 
animation:
@keyframes micPulse {
  0% { box-shadow: 0 4px 20px rgba(124,58,237,0.5); }
  50% { box-shadow: 0 4px 28px rgba(124,58,237,0.8); }
  100% { box-shadow: 0 4px 20px rgba(124,58,237,0.5); }
}
animation: micPulse 2.5s ease-in-out infinite;

State 2 — RECORDING (tap once to start):
Button expands slightly to 64px × 64px
Background changes to #ef4444 (red)
Border changes to #fca5a5 (light red)
Icon changes from microphone to a filled 
red circle (recording indicator)
Box-shadow: 0 4px 28px rgba(239,68,68,0.6)

Add a recording timer that appears above 
the button showing elapsed time:
Format: 0:00, 0:01, 0:02 etc.
Font: DM Sans 700, 13px, white
Background: rgba(239,68,68,0.9)
Border-radius: 20px
Padding: 3px 10px

Add a sound waveform animation around the 
button while recording — 3 concentric rings 
that pulse outward from the button edge:
Color: rgba(239,68,68,0.3)
Animation: expand outward and fade, 
repeat every 1.2 seconds

State 3 — PROCESSING (tap again to stop):
Button returns to 58px
Background: #f59e0b (gold/amber)
Icon: animated spinner or waveform lines
Show small label above button: "Processing..."
Font: DM Sans 400, 11px, #f59e0b

State 4 — COMPLETE:
Button flashes green #22c55e for 600ms
Icon briefly shows a checkmark
Then returns to idle purple state
The transcribed text automatically populates 
the text paste textarea in the Track Sieve
If the textarea already has content, 
append the new transcription on a new line 
rather than replacing existing content

RECORDING IMPLEMENTATION:

Use the Web Speech API (SpeechRecognition) 
for real-time transcription:

const SpeechRecognition = window.SpeechRecognition 
  || window.webkitSpeechRecognition;
const recognition = new SpeechRecognition();
recognition.continuous = true;
recognition.interimResults = true;
recognition.lang = 'en-US';

On recording start: recognition.start()
On recording stop: recognition.stop()

Show interim results in a small preview 
bubble above the floating button while 
recording is in progress:
Background: rgba(10,10,20,0.95)
Border: 1px solid rgba(124,58,237,0.4)
Border-radius: 8px
Padding: 8px 12px
Max-width: 240px
Font: DM Sans 400, 12px, #9ca3af
Position: above the button, right-aligned
Text updates in real time as speech is detected
Italic styling: "Listening... family first always"

On recognition.onresult, extract the final 
transcript and append it to the textarea.

BROWSER COMPATIBILITY HANDLING:

If SpeechRecognition is not available 
(Firefox, some mobile browsers):
Show a fallback modal on button tap:

Modal title: "Voice Drop"
Modal body: 
"Your browser does not support live 
voice transcription. Record a voice 
memo and upload the audio file instead 
— GOATflow will transcribe it."
Show the file upload zone inside the modal
Close button: "Got it"

PERMISSIONS HANDLING:

If microphone permission is denied:
Replace the floating button temporarily 
with a red version showing a 
microphone-with-slash icon
Show a tooltip: 
"Microphone access denied. 
Enable it in browser settings to use Voice Drop."
After 4 seconds return to normal idle state
