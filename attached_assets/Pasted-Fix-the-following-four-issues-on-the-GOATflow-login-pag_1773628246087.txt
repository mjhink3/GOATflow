FIX 1 — LOGIN LOGO CROP
═══════════════════════════════════════

The mascot logo on the login page 
is still being cropped at the top — 
the horns are cut off.

The root cause is a parent container 
with overflow: hidden somewhere above 
the logo image element.

Do the following:

1. Find every ancestor element of the 
   login logo img tag — go all the way 
   up the DOM tree to the body element.
   
2. On EVERY ancestor element, check for 
   and remove or change:
   overflow: hidden → overflow: visible
   clip-path: any value → remove entirely
   max-height: any fixed value → remove
   height: any fixed pixel value that 
     could clip content → change to auto

3. On the logo img element itself set:
   width: 200px
   height: auto
   max-height: none
   object-fit: unset
   overflow: visible
   display: block
   margin: 0 auto
   padding: 0

4. If the logo is inside a flex or 
   grid container set on that container:
   overflow: visible
   align-items: flex-start
   (not center or stretch which can clip)

5. The full mascot must be visible —
   horns at top, face, clipboard, 
   hay badge, GOATflow wordmark, 
   Metabolize tagline at bottom.
   Nothing cut off on any edge.

FIX 2 — DASHBOARD BANNER CROP
═══════════════════════════════════════

The mascot banner on the main dashboard 
is still cropping the top — 
only the lower face shows, 
the horns are cut off.

Same approach as Fix 1 — 
the overflow: hidden is on a parent.

1. Find every ancestor element of the 
   dashboard banner img tag and remove 
   overflow: hidden on all of them.

2. On the banner img element:
   width: 100%
   height: auto
   max-height: 160px
   object-fit: contain
   object-position: center top
   display: block
   overflow: visible

3. object-fit: contain with height: auto 
   will show the FULL image scaled to 
   fit the container width — 
   no cropping on any edge.

4. After this fix the banner will be 
   taller than before. Verify that the 
   Churn Engine button is still visible 
   above the fold. If the button gets 
   pushed below the fold reduce 
   max-height from 160px down in 10px 
   increments until the button is 
   visible — but never crop the image. 
   If it cannot fit at any height 
   without cropping, reduce the logo 
   size on the login page before 
   touching the banner.
