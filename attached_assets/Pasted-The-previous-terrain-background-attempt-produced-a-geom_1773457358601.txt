PARALLAX BEHAVIOR:
Apply this JavaScript scroll listener to create 
the parallax effect on desktop:

window.addEventListener('scroll', () => {
  const scrolled = window.scrollY;
  const layers = document.querySelectorAll('.terrain-layer');
  layers.forEach((layer, index) => {
    const speed = 0.1 + (index * 0.05);
    layer.style.transform = 
      `translateY(${scrolled * speed}px)`;
  });
});

On mobile (window.innerWidth < 768), 
apply the same listener but reduce speed values 
by 50% for smoother mobile performance.
