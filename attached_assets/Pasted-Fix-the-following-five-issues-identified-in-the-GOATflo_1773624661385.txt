FIX 3 — RESET FUNCTION
Fix goatflow_resetOnboarding() to 
also clear the server-side DB flag
═══════════════════════════════════════

Currently goatflow_resetOnboarding() 
clears two localStorage keys but leaves 
onboarding_done = TRUE in the database, 
so the parade never re-fires.

Update the reset function to also 
call a server endpoint that resets 
the DB flag:

window.goatflow_resetOnboarding = 
  async function() {
    localStorage.removeItem(
      'goatflow_onboarding_complete'
    );
    localStorage.removeItem(
      'goatflow_welcomed'
    );
    try {
      await fetch('/api/reset-onboarding', {
        method: 'POST',
        credentials: 'include'
      });
    } catch(e) {
      console.log('DB reset failed:', e);
    }
    location.reload();
  }

Create the server endpoint 
POST /api/reset-onboarding:
- Requires active session (authenticated)
- Sets onboarding_done = FALSE 
  for the current user in the DB
- Returns { success: true }
- Only works for authenticated users — 
  cannot be called without a session

After this fix running 
goatflow_resetOnboarding() in the 
console will fully reset onboarding 
for the logged-in user and the 
parade will fire again on reload.
